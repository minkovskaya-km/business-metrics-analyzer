# Business Metrics Analyzer
Учебный проект по дисциплине «Проектирование и разработка бизнесориентированного программного обеспечения».
## Бизнес-задача
Расчёт и визуализация ключевых показателей эффективности (KPI)
предприятия.
## Стек
- Python 3.10+
- pandas
- matplotlib
## Запуск
python -m venv .venv
source .venv/bin/activate # или .venv\Scripts\activate для
Windows
pip install -r requirements.txt
python main.py

# Пример бизнес-задачи

Небольшая розничная компания хочет ежемесячно отслеживать динамику выручки и понимать, насколько прибыльно работает бизнес. Приложение рассчитывает среднюю выручку за период и показывает рентабельность с учётом себестоимости, что помогает руководителю быстро оценить финансовое состояние компании и принимать решения о расходах.
